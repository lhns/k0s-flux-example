# gears

Compound planetary gear calculator ([lhns/compoundplanetarygearcalculator](https://github.com/lhns/compoundplanetarygearcalculator))
at **`gears.example.com`**. A static Scala.js page served by the image's own Apache httpd; no
state, no auth. The image is pinned to a release tag plus digest, which Renovate updates;
`sha-*` tags from the app repo's CI are not tracked.
